# Learn Mind Mapping with Phoebe

Six 45-minute sessions on shaping what you know into a map with one centre, a handful of
branches and one keyword each - and on knowing when that is the wrong shape.

**Live site:** https://phoebefu6.github.io/learn-mind-mapping-with-phoebe/

| # | Session | Signature thing |
|---|---|---|
| 1 | One centre, many branches | What a mind map is, the ten laws as craft, the evidence read honestly |
| 2 | Keywords and the branch budget | One keyword per branch; four and seven taught side by side |
| 3 | Mind map, concept map, or list | The cross-link test; Novak, Eppler, Davies |
| 4 | The map bench | One outline, five shapes, nine numbers measured off the drawn map |
| 5 | Maps as text | Indentation is the map; version control; when to draw instead |
| 6 | Maps that do work | Plan, brief, decide, revise; the hand-off to an outline |

The bench in session 4 (`assets/map-live.js`) parses any indented outline, draws it as a
radial map, and reads its numbers back off the rendered SVG. There is no recall model
anywhere in it: the evidence on what a mind map does for memory is contested, and the
course teaches the disagreement rather than modelling a side of it.

Every fact, its verification tier and the bench's honest limits:
`materials/official-course-map.md`.

Static HTML, CSS and JS. No build step. by Phoebe Fu.
